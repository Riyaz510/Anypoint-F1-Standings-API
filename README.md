# F1 Standings API

A MuleSoft API that retrieves Formula 1 driver and constructor standings from OpenF1.

## Technologies
- MuleSoft Anypoint Studio
- Mule 4
- RAML 1.0
- DataWeave
- HTTP Connector

## Endpoints

### Driver Standings
GET /api/standings/drivers

### Constructor Standings
GET /api/standings/constructors

## Running the Project

1. Import into Anypoint Studio
2. Run as Mule Application
3. Access:
   - http://localhost:8081/api/standings/drivers
   - http://localhost:8081/api/standings/constructors
